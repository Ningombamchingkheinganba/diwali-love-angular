# A Little Diwali Magic ✨

A romantic, animated Diwali greeting made with Angular standalone components.

## Run locally

```bash
npm install
npm start
```

Open http://localhost:4200

## Personalize the greeting

Edit `src/app/app.component.ts`:
- Replace `Dear beautiful` with her name.
- Change the two message paragraphs to your own words.
- Change the signature in the `signoff` paragraph.

The page includes animated diyas/flames, a glowing lantern, twinkling stars, and a revealable letter with a fireworks-style burst. It also respects reduced-motion accessibility preferences.
